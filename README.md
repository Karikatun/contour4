# Контур-4 / Contour4

Одиночная карта для R.E.P.O. 0.5.2. Включает гравитационное кольцо и процедурный рейд по НИИ «Контур-4».

## Лицензия

[MIT](LICENSE) распространяется на код, права на который принадлежат проекту, включая его скрипты и собранные из него DLL. У моделей, текстур, графики и внешних компонентов свои условия использования. Условия материалов пака предметов приведены в [ASSET-LICENSES.md](ASSET-LICENSES.md).

## Установка

Скачайте [карту 0.2.18](https://github.com/Karikatun/contour4/releases/tag/v0.2.18) и обязательный пак [Contour4 Valuables 0.2.3](https://github.com/Karikatun/contour4-valuables/releases/tag/v0.2.3). Установите оба ZIP в один профиль с BepInExPack 5.4.2305 и REPOLib 4.5.1. Для ручной установки скопируйте папки из каталога plugins каждого ZIP в BepInEx/plugins игры.

Сборка предназначена для предварительного тестирования. Для этой версии остаётся проверить в игре хват, транспортировку и сдачу сердечника.

## Исходники

Код плагина расположен в prototype/ring/Plugin, а генератор и модули процедурного рейда — в prototype/procedural. Для компиляции требуются DLL из локальной установки игры и её модов. Два готовых Unity-бандла входят в ZIP релиза. Подготовка проекта Unity и создание бандлов с нуля требуют авторских ассетов и редакторских скриптов из полного рабочего проекта.
