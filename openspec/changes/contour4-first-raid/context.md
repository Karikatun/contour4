# Контекст

Unity 6000.3.17f1 импортировала исходные FBX. Локальная игра 0.5.2 (Steam 26732417, Unity Player 6000.3.28f1), BepInEx 5.4.23.5 и REPOLib 4.5.1. По LevelGenerator.TileGeneration штатная карта с ModuleAmount = 1 берёт стартовую комнату и обычный модуль без дополнительной точки сдачи. Доступен отдельный тестовый профиль с изоляцией пользовательских данных. Игровые ссылки на фургон и извлечение подставляются из установленной игры при загрузке. [Полное описание карты](../../../GRAVITY-MAP-DESIGN.md).
