В игровой сборке квота расположена внизу, лутовая 1 справа, лутовая 2 наверху, лутовая 3 слева. Unity импортирует авторские FBX и проверяет положение стыков. Одиночный игровой прогон из точного ZIP прошёл из фургона по обоим мостам, через дверной портал между лутовыми 2 и 3 в обе стороны, обратно по мостам и вверх по рампе из квоты в лутовую 3. Первый прототип рассчитан на сольный рейс. В работе использована методика Propose–Probe–Compose, Python-фреймворк Harness2 не запускался.
